# Принятые решения

| № | Решение | Причина |
|---|---|---|
| D1 | Валидируются ответы агента, а не JSON ИР | главное требование `требования.txt` |
| D2 | Арифметика остается у модели, валидатор пересчитывает `expr` | не убирать полезную возможность, но не доверять счету |
| D3 | «Без внутренних знаний» = closed-world контракт ответа | проверяемо: нет источника - нет утверждения |
| D4 | Сжатие ответов - v2 | отложено заказчиком |
| D5 | Автотесты - v2; вместо них ручные сценарии | отложено заказчиком |
| D6 | Пакеты в `src/iacpaas_mcp` и `src/iacpaas_agent` | пробел в старом имени каталога ломал упаковку |
| D7 | Базовый URL IACPaaS захардкожен, секреты из `.env`/окружения | прототип, без слоя настроек |
| D8 | `list_inforesources` на локальном каталоге | в API нет перечисления ИР |
| D9 | MCP-тулзы оборачиваются через `fastmcp.Client`, без `langchain-mcp-adapters` | адаптер несовместим с MCP 2.3, который требует FastMCP 4 |
| D10 | Нечисловые утверждения проверяются по `value` или дословной `quote` | `statement` не сравнивается с данными; без проверяемого payload claim отклоняется |
| D11 | Веб-чат на FastAPI и одной HTML-странице | без Node и сборки; тот же `run_agent`, read-only |
| D12 | История последних 3 ходов передается в модель, evidence прошлых вызовов доступен валидатору | follow-up работает, а каждое новое утверждение все равно проверяется |
