## Что именно гарантирует валидатор

Проверяются только утверждения из `AgentAnswer.claims`:

- `call_id` существует в `evidence`;
- JSON Pointer разрешается в результате вызова;
- значение совпадает с данными (строки сравниваются с нормализацией регистра,
  Unicode и пробелов);
- для текстового факта проверяется точная `quote` из источника;
- claim без `value`, `quote` или формулы отклоняется;
- формула в `expr` пересчитывается;
- источник не является ошибкой тулза;
- при `truncated=true` нельзя утверждать «всего/количество»;
- ответ без вызовов тулзов отклоняется.

## Честные ограничения

- Свободный текст `answer` не сверяется с данными пословно; гарантия относится к claims.
- `temperature=0` не делает ответ LLM побитово воспроизводимым. Воспроизводим вердикт
  валидатора, а не генерация модели.
- В VS Code валидатор работает в режиме Cline-плагина: `submit_answer` - единственный
  completion tool, `submit_and_exit` и write-тулзы блокируются.
- Cline-плагин требует Cline 4.0+ и запускает Python-мост валидатора через `uv`.
- Сжатие контекста и автотесты - v2.
- LLM-judge для смыслового соответствия не реализован.
- Веб-чат локальный, без авторизации: все чаты в SQLite видны на этой машине.
- Чаты не удаляются, база растет; длина контекста оценивается как `chars / 3`.
